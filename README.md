# Build your own POM — course slides

Slides for a 90-minute hands-on course: connect your own Claude Code to Google Colab, tour a TV-news monitoring system (POM, Public Opinion Monitor), run a small version of it, extend it in teams, and share the result.

Open the slides: https://allenphant.github.io/pom-course/

Keys: arrow keys or space to move, `O` overview, `L` laser pointer, `S` presenter window.

This repository only holds the published page. The course source is kept elsewhere.
